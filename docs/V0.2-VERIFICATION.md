## 兼容与启用

保留原公开监控前台、登录、监控指标、4 秒采集、连接密钥验证、安装/卸载。新客户端通过带认证的协议协商决定是否附带 v0.2 扩展，因此可继续连接 v0.1 服务端。旧客户端连接 v0.2 服务端仍可上报原指标，但不能执行新增管理操作。

管理默认关闭。Linux root 主机管理员通过安装弹窗选择“启用 v0.2 运维管理”，或为客户端明确添加 `--management`，才可执行固定管理功能。主机目录与服务白名单只能在客户端本地配置，网页角色不能扩展白名单。Windows 继续监控和系统信息采集，不支持 Linux 管理动作。

文件上传限制为 32 KiB UTF-8 文本和新增文件；不覆盖、不删除、不执行。预定义命令没有自由 shell。操作超时不证明未执行，需刷新目标状态后决定是否重新发起。常见敏感日志字段会脱敏，但不能保证识别任意应用输出中的所有秘密；具体边界见 `SECURITY.md`。

## 仍需目标环境验收

本机没有可用 Linux 运行环境，未安装 WSL、Docker 或其他无关软件。交叉编译和模拟执行器不能代替真机操作验证。上线前在一次性 Linux 测试主机验收：

1. 选择运维模式安装并检查 root 服务及 systemd 沙箱；默认监控模式保持原低权限运行。
2. 为一次性测试容器验证状态/列表/日志/启动/停止/重启。
3. 为白名单测试服务验证状态和 start/stop/restart，确认 SSH 与关键系统服务被拒绝。
4. 在专用允许目录验证文件浏览/上传/下载和 Linux 符号链接/硬链接/特殊文件防护。
5. 使用三种角色从实际浏览器检查全部页面、取消/错误提示及审计记录；本次只验证构建和页面路由响应，没有声称完成视觉或逐项 UI 交互验收。

上述验收不应直接使用生产服务、生产容器或生产工作目录。本次没有进行生产环境变更。
