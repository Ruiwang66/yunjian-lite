# v0.5 自身安全审查与修复

检查日期：2026-11-04（Asia/Shanghai）。范围是当前仓库的控制端、Agent、浏览器、存储和部署模板。没有探测生产系统、修改其他网站/SSH/防火墙，也没有增加安全扫描业务模块。本报告不是安全认证或完整形式化证明。

## 基线与信任边界

工作仓库位于 `github-v04-release-20261030/repository`。HEAD 是 v0.3，但开始时工作文件/索引已有 54 个 v0.4 暂存改动，未暂存修改为空；以这份 v0.4 工作树为基线，未改动原索引。原文件和差异保存在 `.runtime/v05-baseline/`。

匿名用户可看明确公开的监控；admin/operator/viewer 共享管理工作区，不是多租户。服务器并不私属于某个普通用户，不能把共享访问误报成越权。任务临时结果是发起者/admin 范围；安全中心限 admin/operator，通知已读按用户记录。Agent 密钥只代表绑定节点，不能充当管理员会话；主机本地白名单/实际执行身份是第二道边界。代理只在配置 CIDR 内可信；所有 Agent 和外部 DNS/HTTP/TLS/日志数据都不能自动成为授权依据。

## 已确认并修复的问题

以下测试均使用临时数据库/测试账号或回环模拟服务。通用回滚 R0：复核文件差异后恢复旧代码/程序，保留最新数据；会重新引入对应问题，禁止覆盖用户原暂存内容或生产新数据。配置、行为和回滚细节见 [升级说明](V0.5-UPGRADE.md)。

### F01 · 高 · 登录与改密竞争（已确认、已修复）

- **定位/链路：** `server/api/auth.go: login`，读取哈希 → bcrypt → 创建 session。
- **前提/影响：** 登录已读旧哈希时，另一个请求完成密码重置；原实现在重置之后仍能为旧密码建立新有效会话。
- **最小验证：** `TestV05PasswordResetDuringLoginCannotMintStaleSession` 用查询屏障安排并发，不碰真实账户；修复前返回 200，修复后 401 且不下发 Cookie。
- **修复：** bcrypt 仍在写事务外执行；签发时事务内检查用户、原哈希和当前角色，返回当前用户信息。
- **兼容/性能：** 保留 bcrypt/随机会话/原 Cookie；增加一次短事务读取，重置期间旧密码登录被明确拒绝。
- **验证/回滚：** 回归通过；R0，不需要数据迁移。

### F02 · 高 · 任务回传缺少创建者授权复核（已确认、已修复）

- **定位/链路：** `server/api/management.go: nextOperation, operationResult, taskAuthorized, cancelTask`。
- **前提/影响：** 任务已领取后创建者退出、过期、角色/能力被撤销，旧租约原本仍可将数据写入 Docker/网站/安全等缓存并标记成功。
- **最小验证：** `TestV05RevokedSessionCannotCommitTaskResult` 对退出/过期/无效角色分别复现，原为 200，现为 409 且缓存不变；原跨节点、租约、重复和超时测试继续通过。
- **修复：** 领取和回传共同检查持久化会话/角色、节点密钥、Linux 管理状态、写权限、本地报告的范围；能力只能缩小已有授权。精确到期时刻也判过期。
- **兼容/性能：** 不改协议，不重发已领取任务；新增短查询。已在远端执行的动作不能撤回，取消/超时不等于“没有执行”。Agent 最终仍按本机白名单执行，自报能力不是特权证明。
- **验证/回滚：** 回归通过；R0，临时输出不进入审计。

### F03 · 中 · 私有会话延迟停推及公开通知串用（已确认、已修复）

- **定位/链路：** `server/websocket/hub.go: Serve/ServePublic/Broadcast`，`server/api/router.go`。
- **前提/影响：** 原会话仅每 25 秒复核，撤销后仍可能收到队列通知；公开通道也接收 `security_changed` 等活动类型。消息本身只有类型/时间，不是完整任务输出或凭据泄露。
- **最小验证：** `TestV05RevokedSessionStopsNotificationsImmediately` 修复前收到撤销后的通知；现关闭。公开白名单、NAT 独立账户槽位、失败 upgrade/释放/通知专用连接测试通过。
- **修复：** 每次发送前检查过期与会话；公开连接只接收监控/节点变化；私有按认证账户限额。
- **兼容/性能：** 公共地图和 4 秒轮询保留；每私有通知增加会话查询；空闲连接最迟心跳关闭，已经在途的帧不能撤回。
- **验证/回滚：** WS 集成和浏览器通过；R0。

### F04 · 中 · NAT 共享 API 额度与登录容量边界（已确认、已修复）

- **定位/链路：** `server/api/security.go: requestLimiter/securityHeaders/requestBudget`、`router.go: auth/allowLogin`、`installer.go: agentInstallAuth`。
- **前提/影响：** 原所有 API 共用来源的 5/s、60 突发额度；独立 Agent 在同一 NAT 下互相阻塞。登录 map 满时也拒绝已有未超限组合。
- **最小验证：** 80 个节点同来源握手测试原在第 57 个失败，现全部通过；单个 Agent 仍会限流。伪造 XFF/X-Real-IP 不能绕过；公共洪流不消耗用户/Agent 预算；10,000 键和闲置清理测试通过。
- **修复：** 区分公开/私有/Agent 入口及认证身份，采用独立键空间；保留来源、身份与内存边界，修复满 map 对已有键的判断。
- **兼容/性能：** 不增加代理信任、不配置 IP 黑名单；额度见升级说明。没有声称可以抵御全部带宽型 DDoS。
- **验证/回滚：** API/安装夹具通过；R0，回退会恢复 NAT 竞争。

### F05 · 中 · Agent 时间可污染网站缓存（已确认、已修复）

- **定位/链路：** `server/api/agent.go: report/validReport`、`websites.go: validWebsiteCheck/cacheWebsiteCheck`。
- **前提/影响：** 合法节点凭据可上报远期 `checked_at`，原代码直接作为缓存时间，影响新结果覆盖和时间展示；网络速率原来也只检查有限值/非负。
- **最小验证：** `TestV05AgentCannotPoisonWebsiteCacheTime` 原接受一年后时间，现 400；原指标非有限值、整数溢出、重放/轮换测试通过。
- **修复：** 检查时间正值/超前边界，持久化使用服务端 UTC，允许合法结果纠正已有异常远期缓存；速率增加数值上界。
- **兼容/性能：** 不改字段和正常 Agent 协议，不使用 Agent 时间决定在线或监控清理；增加常数时间检查。
- **验证/回滚：** 回归通过；R0，保留现有监控历史。

### F06 · 中 · Agent 永久无效结果阻塞队列（已确认、已修复）

- **定位/链路：** `agent/operations.go: managementLoop`。
- **前提/影响：** 服务端对结果持续返回 400，原 Agent 每 2 秒无限重试，从此不领取后续任务。
- **最小验证：** `TestV05RejectedResultDoesNotBlockAllFutureTasks` 原 9 秒内不能再次领取，修复后 6 秒左右恢复领取；只用返回错误的禁用管理器和回环模拟控制端。
- **修复：** 永久 4xx（除 408/429）停止重试，临时错误受任务期限/最多两分钟约束；只重传结果，不重做动作。
- **兼容/性能：** 协议不变，旧 Agent 要更新才能获得此修复；减少无效流量，超时仍代表状态可能未知。
- **验证/回滚：** 集成通过；R0，回退保留旧重试缺陷。

### F08 · 中/条件性 · IPv6 特殊目标边界补缺（已确认、已修复）

- **定位/链路：** `agent/management/website_probe.go: publicAddress/probeWebsiteUsing`。
- **前提/影响：** 需要已授权网站域名及可路由的特殊 IPv6 环境；部分旧站点本地/兼容/转换地址未被原公网策略排除。不是任意匿名 URL 代理。

### F09 · 中 · 初始化密码文件竞争（已确认代码竞争、已修复）

- **定位/链路：** `server/service/auth.go: BootstrapAdmin`，原查询/文件写入在创建事务之外。
- **前提/影响：** 两个进程同时首次启动或重置，失败方的文件回退可能删除/覆盖成功方的密码文件，造成持久化哈希与初始凭据不一致。
- **最小验证：** 临时目录双 goroutine 初始化一致性、已有独占锁时拒绝改库；不重置真实账户。
- **修复：** 私有数据目录内原子独占文件锁，持锁后重查用户；只由持锁者回退文件。
- **兼容/性能：** 普通已有管理员启动仍不重置；异常退出可能残留锁，处理条件见升级说明；只影响初始化阶段。
- **验证/回滚：** 一致性/锁释放及旧初始化测试通过；R0，不能并发重置管理员。

### F10 · 中（稳定性） · 下载与短 API 共用期限（已确认、已修复）

- **定位/链路：** `server/main.go` 的 20 秒 WriteTimeout、`server/api/downloads.go: downloadAgent`。
- **前提/影响：** 最大 64 MiB 的固定程序包在慢链路超过 20 秒，原全局期限可能截断安装包。
- **最小验证：** 控制 ResponseWriter 验证下载单独设置 5 分钟期限，内容/鉴权仍正确，满 16 个传输时 503 并带 Retry-After；未做实际五分钟慢网测试。
- **修复：** 独立且有界的下载写期限及并发槽，保留短 API 和 WS 自有期限。
- **兼容/性能：** 增加同时传输上限，大批部署要错峰；不会延长所有请求。应用、代理示例均有边界。
- **验证/回滚：** API 和二进制校验 smoke 通过；R0。

### F12 · 中（稳定性） · 前端异步过时响应（已确认、已修复）

- **定位/链路：** `web/src/refresh.js`、Dashboard/Server/Logs/Operations、`management.js`、`state.js`。

### F13 · 中（稳定性） · 历史清理写放大/长批次（已确认、已修复）
