# 部署配置说明

本文是脱敏的部署模板，不代表任何线上环境的实时状态。完整步骤见[安装与运维](INSTALL.md)。

## 公网部署建议

- 后端默认只监听 `127.0.0.1:5050`，通过 HTTPS 反向代理提供公网访问。
- 将 `PUBLIC_URL` 设置为实际 HTTPS 地址；反向代理保留 Host 并转发 WebSocket Upgrade。
- 只把核实过的代理网段写入 `TRUSTED_PROXY_CIDRS`，不要信任 `0.0.0.0/0`。
- 首次管理员密码只生成一次，从私有数据卷读取；登录后立即修改，不要把密码或连接密钥写进文档、命令历史或日志。
- 更新前备份数据库和旧程序，保留 Docker 命名卷。不要使用 `docker compose down -v`。
- 先升级监控客户端，再关闭 `ALLOW_LEGACY_REPORTS`；生产环境保持重放保护启用。
- 首次 SSH 连接必须独立核对主机公钥指纹；不要自动接受未知公钥。

部署示例中的域名和路径仅作说明。每个环境应单独配置 TLS、反向代理、防火墙、备份和恢复演练。
