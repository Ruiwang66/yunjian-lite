## 实际浏览器和 API 验收

使用 `127.0.0.1:5054` 独立本地夹具。Linux/SSH/证书输入在服务器名称、黄色提示和报告范围中明确标注模拟，不代表 Windows 开发机或真实远程 Linux 的状态。

- 界面走通排队→完成，返回评分、未确认覆盖、依据和建议。
- 将 root 密码登录风险标记为误报，原始证据和 73 分参考评分保持不变，审计仍存在。
- 两条高风险通知可分别标已读；数据库测试确认已读按用户隔离。
- 报告显示模拟范围和规则结果，JSON 查询通过；不把演示当作真实 Linux 验收。
- `tests/security-v04-smoke.py` 确认 viewer 拒绝、普通模式扫描拒绝、非法路径拒绝、跨服务器报告拒绝、风险筛选与公开接口无安全数据。
- 同一脚本短时运行普通 Windows 客户端验证真实 4 秒采集，随后停止程序，不创建启动任务。本地库的普通监控与 Windows 样本稍后显示离线是预期行为。

## 资源验证范围

代码限制：固定工具、单命令超时、扫描 35 秒/租约 45 秒、单机一次任务、全局最多 4 个安全任务、单次结果 45 KiB、Docker 最多 20 个容器、每文件日志 64 KiB、窗口最多 4096 条事件、网站单层有界元数据，不进行全盘递归。
