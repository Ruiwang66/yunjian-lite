## 严重风险

### C-01 公网 HTTP 下载并以管理员身份执行安装内容

**影响：** 旧复制命令及脚本接受公网 HTTP，网络中间人可能替换安装/卸载脚本。旧脚本还以 root/管理员执行下载程序的 --help 检查，程序替换具有主机级影响。  
**位置：** `TokenSetup.vue`、`RemoveServer.vue`、`server/api/install/agent.sh`、`agent.ps1`、`agent/main.go`、`shared/security.go`。  
**描述性复现：** 隔离场景把控制台地址设为公网 HTTP，查看旧 URL 校验和生成命令：不会拒绝该地址且下载后继续执行。无需替换程序或测试外部主机。  
**修复：已完成。** 页面、脚本、客户端独立拒绝公网 HTTP，仅允许 HTTPS/回环 HTTP；正常验证 TLS，不跟随重定向；二进制执行前校验 SHA-256 和 ELF/PE 文件头，取消管理员身份的 --help 执行。  
**边界：** 第一个脚本仍信任 HTTPS 控制台；同源哈希不是独立签名，不能抵御控制台被攻陷。显式 --allow-insecure-http 仅为隔离开发保留。

## 高风险

### H-01 连接密钥进入复制命令、历史和进程参数

**影响：** 终端记录、shell history、进程参数和截图可能泄露密钥；持有人能冒充该服务器，不能凭此自动获得后台 Cookie 权限。  
**位置：** `web/src/components/TokenSetup.vue`及安装脚本。  
**描述性复现：** 旧命令的 --key / -Key 参数直接包含原密钥，shell 会记录并向子进程传递。  
**修复：已完成。** 命令不再含密钥，弹窗独立提供遮蔽密钥/复制按钮，脚本隐藏交互读取；无人值守使用受限密钥文件，服务参数只有文件路径。  
**边界：** 旧 CLI 参数保留兼容性，主动使用仍可能暴露。复制密钥会进入剪贴板，应妥善处理。

### H-02 Windows 采集任务运行于 SYSTEM

**影响：** 采集所需权限低于 SYSTEM；程序漏洞或替换会放大主机影响。  
**位置：** `server/api/install/agent.ps1`。  
**描述性复现：** 旧任务 Principal 为 SYSTEM；结合程序替换路径即可确认权限扩大，不需要实际安装任务。  
**修复：已完成。** 改用 LocalService（S-1-5-19）、Limited，密钥只读，二进制只读/执行；安装阶段仍需管理员。[Microsoft LocalService 文档](https://learn.microsoft.com/en-us/windows/win32/services/localservice-account)。  
**验证边界：** 语法和 Principal/ACL 构造通过 mock fixture；没有注册真实任务。目标 Windows Server 的启动和采集能力仍需验证。

### H-03 匿名 API 与 WebSocket 缺少统一资源限制

**影响：** 大量连接/请求占用内存、网络和 SQLite 单连接。历史查询原已有时间范围上限，不误报为无限时间查询。  
**位置：** `server/websocket/hub.go`、`server/api/security.go`、`auth.go`。  
**描述性复现：** 旧 Hub 登记连接没有总量/IP 上限；本地低限额 fixture 验证边界，无需公网压测。  
**修复：已完成。** API 每 IP 5 次/秒、突发 60，最多 10000 键并清理；bcrypt 登录并发 4，保留失败次数限制。WS 总量 256、每 IP 8、读消息 1 KiB、队列 8，禁止应用消息（关闭码 1008）；失败升级/退出释放名额，关闭 Hub 清理连接；IP 通过明确可信代理校验。  
**边界：** 同 NAT/代理用户共享限额；不能代替边缘抗 DDoS 或大规模负载验证。

### H-04 数据与秘密文件可能继承宽松权限

**影响：** 旧目录/DB 模式及 Windows POSIX chmod 不足以限制本机其他账户访问数据、会话/密钥哈希和首次密码。  
**位置：** `internal/privatefs/`、数据库、密码初始化、客户端与安装脚本。  
**描述性复现：** 比较创建权限与默认 umask；Windows 检查继承 DACL，不能把 chmod(0600) 当作 NTFS 私有 ACL。  
**修复：已完成。** Unix 数据目录 0700、数据库/密码 0600，服务密钥 root:服务组 0640；Windows 受保护 ACL，限定当前账户/SYSTEM/管理员，服务文件允许 LocalService 读取。秘密读取拒绝链接、非普通/大文件和宽松 ACL，并核对打开后的文件身份。密码原子替换，DB 操作失败恢复旧文件；文件写入失败不继续提交未知密码。  
**边界：** 不提供磁盘加密；主机管理员仍可读取。父路径必须可信，不声称消除管理员参与的全部文件竞态。

## 中风险

### M-01 上报缺少时间与重放约束

**影响：** 已捕获报告可在稍后重复提交，3 秒限流不能识别新旧。有效密钥持有人仍可伪造自己的指标，nonce 不证明真实采样。  
**位置：** `shared/metrics.go`、客户端、`server/api/agent.go`、`models.go`。  
**描述性复现：** 本地 fixture 重复提交同一合法报告，旧协议没有持久化新鲜度标识。  
**修复：已完成。** 毫秒 sent_at + 16 随机字节 base64url nonce，默认必填，允许五分钟偏差；事务拒绝不大于已提交时间戳或重复标识，409 且不追加指标，重启保留状态；轮换密钥重置旧新鲜度状态，防止旧密钥提交未来时间阻碍新客户端。  
**边界：** 不是 HMAC 签名；TLS/密钥仍是认证基础。ALLOW_LEGACY_REPORTS=true 降低旧报告保护，仅作临时迁移；时钟回拨需同步时钟。

### M-02 输入及 SQLite 整数边界不够严格

**影响：** 未知字段/尾随值造成协议歧义，超出 SQLite 有符号整数的 uint64 导致持久化错误，异常 ID 不应进入查询层。  
**位置：** `server/api/security.go`、`agent.go`、`servers.go`、`auth.go`。  
**描述性复现：** 隔离用例提交额外字段、第二个 JSON、超大体、负 ID、MaxUint64；应拒绝且不写数据。  
**修复：已完成。** application/json、单值、未知字段和 64 KiB 校验；正整数 ID、字符串/容量/核心数/百分比/速率验证，持久化 uint64 不超过 MaxInt64，拒绝非有限值；保留参数化查询、日志等级白名单和历史 1–24 小时/约 1200 点。

### M-03 日志可能输出 SQL 参数和请求信息

**位置：** `server/database/database.go`、`server/api/router.go`。  
**影响/描述性复现：** 旧 ORM 错误日志可带参数；默认 panic 恢复存在记录请求内容风险，检查配置即可发现，无需触发生产错误。  
**修复：已完成。** ParameterizedQueries=true；panic 仅记录泛化错误，不打印请求头/恢复值；外部错误不暴露 SQL，事件日志不写原密钥/密码/Cookie。  
**边界：** 反代与系统日志由部署者另行确认。

### M-04 明文公网默认绑定与来源约束不足

**位置：** 配置、security.go、Compose、.env.example。  
**影响/描述性复现：** 旧 Compose 默认所有网卡、Secure Cookie 关闭，HTTP 管理会暴露凭据。检查默认配置及来源判断，不测试第三方。  
**修复：已完成。** 默认回环绑定；PUBLIC_URL 限制到 HTTPS/回环 HTTP，固定管理 Host、写请求/WS 完整 Origin；HTTPS 自动 Secure、HSTS。默认不信任转发头，明确 CIDR 才生效；拒绝 /0 全地址信任和无效布尔配置。会话校验关联用户，孤立会话拒绝；保留 HttpOnly/SameSite Strict。  
**边界：** 操作者能改为公网绑定/错误 CIDR；依靠可信反代终止 TLS，不自动申请证书，截至本次源码审计时未验证线上 TLS/防火墙。

### M-05 quic-go 已知 HTTP/3 依赖漏洞

**位置：** `go.mod/go.sum`、第三方清单。  
**证据：** v0.59.0 的 GO-2026-5676（CVE-2026-40898 / GHSA-vvgj-x9jq-8cj9），HTTP/3 QPACK Trailer 内存耗尽，v0.59.1 修复。[Go 官方漏洞条目](https://pkg.go.dev/vuln/GO-2026-5676)。  
**适用性/复现边界：** Gin 引入依赖，扫描存在包/符号记录；本项目 main 使用标准 HTTP ListenAndServe，未启用 HTTP/3。静态接口路径不等于已证实能从当前入口利用；不提供外部利用测试。  
**修复：已完成。** 升级 v0.59.1、更新清单，测试/编译通过，复查该告警消失。

**修复：已完成。** 文档使用脱敏示例、历史注明时效；排除 .env 变体、数据库、日志、首次密码、备份、常见密钥/证书、缓存和提示词；保留许可证/贡献指南，新增 SECURITY.md。

**处理：已完成。** 110 个依赖，包括 @sxzz/popperjs-es 别名，全部原哈希与官方一致；改用官方归档来源，版本和 integrity 不变。官方 npm ci/构建通过。没有发现包篡改证据。

## 十个领域的补充结论

1. **结构/秘密：** server/agent/shared 分离，privatefs 集中权限处理。待发布源码未检出真实密码、密钥或私钥，fixture 固定值为合成数据。缓存/运行历史/证据保留在忽略目录，不做破坏性清理。
2. **Go/授权：** 管理 Cookie 和客户端 Bearer 不互通；原密钥只在创建/轮换返回，DTO 不序列化哈希。单工作区没有普通用户或多租户模型，不虚构跨租户漏洞。密码 bcrypt，随机密钥 32 字节，未知用户名也做 bcrypt。新密码 12–72 字节，没有自动重置既有密码。
3. **WS：** 只有通知，不接受远程命令；公开 WS 仅类型与时间。会话到期关闭，撤销最长 25 秒。默认同 Host 检查加 API 完整来源检查。
4. **客户端：** 无远程 shell/脚本下发；正常 TLS、禁止重定向、有响应读取上限，每 4 秒采样/重试。更新由操作员完成，不伪装成自动更新系统。
5. **API：** 未发现公开增删/密钥/日志权限。公开名称、规格、指标是用户要求的行为，避免写敏感名称。没有用户 URL 抓取业务，不把人工客户端地址误报为服务端 SSRF。
6. **DB：** SQLite 无网络端口；参数化查询，动态 Group 只拼代码计算整数，清理列为常量；默认七天保留、事务删除。无应用加密/磁盘配额，需容量监控与备份。
7. **Docker：** 保留 scratch、UID/GID 10001、只读、cap_drop ALL、no-new-privileges、持久卷、256 MiB/日志轮转；新增回环/PID 128。无 Docker socket/privileged。目标容器未实测。
8. **前端：** 开发代理已补入安装/卸载脚本路径；Vue 文本渲染，无业务 v-html/innerHTML，会话不进 localStorage/URL；密钥短期留在弹窗内存。前端校验不代替服务端授权。
9. **依赖：** Go 复查只剩 GO-2026-5932 的模块级提示，涉及不维护的 x/crypto/openpgp。[官方条目](https://pkg.go.dev/vuln/GO-2026-5932)。依赖图没有 OpenPGP 包/符号，仅使用该模块 bcrypt 等，不误报密码存储或删除 bcrypt。Npm 官方审计 0 已知漏洞；按真实包名（包括别名）核对了全部 110 个依赖，原 integrity 均与官方一致。全部下载 URL 改为官方 tarball，版本/哈希保持不变。@popperjs/core 的真实包是 @sxzz/popperjs-es；早期按目录名进行的比较误把两个包对照，已纠正，不是供应链篡改证据。审计时使用的临时完整性核对材料未随仓库发布；[别名包官方元数据](https://registry.npmjs.org/@sxzz%2fpopperjs-es/2.11.8)。
10. **网络/开源：** 本次未检查线上 OS/宝塔、WAF、TLS、安全组与证书；MIT、第三方许可保留。SECURITY.md 要求私下报告但不虚构联系地址。

## 架构安全建议

- 保持采集与未来管理功能分离；容器/网站/证书管理先设计角色、权限、审计和最小权限，避免把任意远程执行混入上报协议。
- 当前没有 MFA/多租户；若面向互不信任的后台用户，先增加数据归属，不能直接复用单工作区全管理权限。
- 更强软件来源验证需要独立签名/客户端证书，同源 SHA-256 不能当作发布签名。
- 大规模部署增加批量最新值查询、历史缓存、全局并发与磁盘配额；限额应按负载证据调整，不能盲目取消。

## 部署安全建议

- 升级前备份数据库与旧程序，PUBLIC_URL 配实际 HTTPS 域名，5050 保持回环，对公网只开放必要 443。
- 反代保留 Host/Upgrade，覆盖不可信转发头，只信任核实 CIDR。
- 推荐先升级客户端再控制台。新安装脚本需要 checksum 接口，旧控制台不具备完整流程；跨版本可手动更新客户端，或短期开 ALLOW_LEGACY_REPORTS 升级控制台，再升级客户端并关闭开关。
- 同步时钟，一条记录只运行一个客户端。目标验证 Windows LocalService/卷权限、Linux 服务账户/0640 密钥。
- SSH 指纹独立核对；首次登录更改随机密码，暴露的真实凭据由操作员更换。本次没有重置任何既有管理员密码。
