# v0.6.0 外观与 Modern 节点看板

本版基于 2026-11-06 的 v0.5 发布包增量开发。公开首页采用五格总览和紧凑节点卡；后台服务器列表共享卡片，原有运维和权限结构保留。没有业务数据库迁移。

## 在哪里调整

- 公开页、登录页、后台顶栏的太阳／月亮按钮：浅色、深色、跟随系统，以及关闭／轻盈／通透材质。
- 后台「设置 → 外观与布局」：四种强调色、后台信息密度、动效及分组恢复默认。
- 「设置 → 概览布局」：调整地图与最近活动顺序，以及进入概览时是否展开地图。统计始终在首位；服务器列表不受这个顺序影响。

默认浅色、鸢紫、紧凑节点布局、舒适密度、轻盈玻璃、动效跟随系统。系统要求减少动效时优先尊重系统。公开地图初始折叠，后台地图默认展开；当次临时收合不覆盖保存的默认值。

## 偏好保存在哪里

外观使用本站点 localStorage 的 `cloudease.appearance.v1`，同源标签页同步。后台布局使用 `cloudease.dashboard.v1.<userId>`，按本机浏览器中的账户区分。退出会清除上一账户的内存布局，下次登录再读取。没有跨设备同步或服务端偏好表。

存储不可用时，本次页面内仍可换肤；设置页显示「本次浏览有效」。损坏 JSON 恢复默认，未知字段或枚举不执行、不应用。清理站点数据会删除本机偏好。

## 看板数字的含义

- 总览统计所有节点；搜索只改变卡片集合。地区支持名称和代码搜索，也可搜节点名、系统；后台继续支持 IP 搜索。
- 累计流量是有样本节点本次开机以来累计上传／下载之和，缺样本时标明覆盖数。重启可下降，不代表月账单或配额。
- 速率只汇总在线节点，按新样本积累最近约 60 秒趋势，同一批样本不重复加点，长时间断线不连线。
- 真实零显示 0，缺失显示「—」。离线卡片显示状态和最后上报，旧读数不是实时状态。
- 没有新增 Load、KVM 或流量配额字段。地区取本地国家码映射；国旗使用随前端打包的 SVG，Windows 上也显示图形，未知地区使用中性图标。

## 升级和回退

沿用 v0.5 配置、代理、持久化卷和 Agent 协议。主题脚本为同源、阻塞的小脚本 `/assets/appearance-init.js`，在首屏绘制前应用偏好；继续使用现有 `script-src 'self'`。需要将它与整套 `web/dist` 一同发布，不能只替换 index.html。

Server、前端 package/lockfile、侧栏、登录标识及 compose 标签更新为 0.6.0。Agent 业务未增加能力；候选二进制重新构建以保持版本一致。按旧授权工作，未新增入站端口、角色或系统权限。

先在预发布实例核对实际镜像是否存在、镜像标签与 compose 是否一致，再检查 `/healthz`、静态资源、公开页及登录后后台。v0.6.0 已于 2026-11-11 部署并完成基础线上核验；源码于 2026-11-25 上传至 GitHub `main`，未创建单独 Release。其余目标环境验收边界见 [验证记录](V0.6-VERIFICATION.md)。

回退保留 v0.5 镜像和整套静态文件，切回后检查其引用的哈希资源仍然可取。纯 UI 回退不恢复旧数据库，也不覆盖运行期间产生的新监控数据；旧版会忽略新增浏览器偏好。保留完整备份仍是发布前提。

## 本地预览

使用 `scripts/local-v03-preview.go` 的隔离夹具，或已构建的 `.runtime/v06-preview.exe`：

```powershell
go run -tags nomsgpack ./scripts/local-v03-preview.go -root .runtime/v06-preview -web web/dist -listen 127.0.0.1:5059 -security-demo
```

本地夹具提供 admin/operator/viewer 测试账户，只绑定回环地址；Linux 管理及安全输入是模拟数据，不用于线上部署。浏览器测试从 `CLOUDEASE_TEST_PASSWORD` 环境变量读取本机测试凭据，仓库不保存口令。八节点视觉样例由浏览器测试拦截本机公开响应生成，产品没有内置假节点。

构建与验收范围见 [验证记录](V0.6-VERIFICATION.md)，性能测量见 [性能记录](V0.6-PERFORMANCE.md)。跨设备同步、壁纸、任意取色、拖拽画布和 AI 诊断未纳入本版。

节点列表只保留紧凑布局，已移除 Modern 和布局选择器；旧浏览器保存的 Modern 值自动归一为紧凑，其他外观偏好保留。后台信息密度仍独立设置。
