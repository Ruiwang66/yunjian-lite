# v0.6 性能记录

日期：2026-11-11。仅限本机 Windows / Chrome 157 headless，不能换算成生产性能或真机帧率保证。

## 首屏资源

同一份 v0.5 发布产物与 v0.6 生产产物，按首屏 index JS、CSS 加阻塞主题脚本分别做 gzip 后求和。v0.5 为 419,153 字节；v0.6 增量约 8.6KB，低于提案的 20KB 预算。精确大小、产物名见 `.runtime/v06/performance.json` 和交付清单。

没有引入新的产品依赖。主 JS 仍约 1.116MB，原有500KB体积提示仍在；未以调高告警阈值掩盖它。地图保持独立异步块。

## 滚动对照

同一 Chrome、1440×900、同批八节点、同一回环 API 夹具，分别测 v0.5、v0.6 关闭玻璃、v0.6 轻盈玻璃。每模式三轮，每轮15秒；使用 requestAnimationFrame 记录帧间隔，统一以超过16.7ms计慢帧；同时保存滚动 webm。

| 模式 | 三轮慢帧比例 | 中位数 |
| --- | --- | --- |
| v0.5 | 0%、0%、0% | 0% |
| v0.6 关闭 | 0%、0%、0% | 0% |
| v0.6 轻盈 | 0%、0%、0% | 0% |

轻盈比关闭增加0个百分点。实际回调间隔中位数约6.1ms（约165Hz），不是60Hz真机；16.7ms是本次固定比较阈值。headless、录屏开销、宿主显示环境和短时数据量均限制结论。测量后仅修正语义颜色、可访问标签、选中态及登录自动填充样式，未改动滚动布局或滤镜区域；不把这些结果称为全部设备流畅保证。

颜色修正后单独复核56组语义配色；最终资源大小单独刷新，不重复无关滚动样本。原始九轮数据完整保留，没有挑选最快一轮。
