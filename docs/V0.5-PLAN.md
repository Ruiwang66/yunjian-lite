## 真实基线

- Go/Gin/GORM/纯 Go SQLite，Vue 3/Vite/Element Plus；不存在前端类型检查、Lint 或单元测试脚本。已存在安装夹具、地图测试及 Go 集成测试。
- Git HEAD 为 v0.3 提交 `c2f2ed9`，工作文件和索引包含 54 项 v0.4 已暂存修改；开始时未暂存修改为空。不能用 HEAD 代替 v0.4 基线。287 个工作文件、哈希和原始差异保存在忽略目录 `.runtime/v05-baseline/`，不改变索引。
- 复用既有项目内 Go 1.27.1，Node 24.16.0/npm 11.13.0；测试缓存和数据位于本仓库。没有全局安装。
- 首轮受限环境测试的回环 HTTP/WS 被操作系统拒绝；允许回环网络后，原有全量 Go 测试通过。前端基线构建结果见测试报告。
- admin/operator/viewer 共享服务器工作区；任务结果仅发起者/admin 可读，安全中心限 admin/operator。不要新增多租户、角色或管理能力。
- Agent 使用 Bearer 哈希绑定服务器；仅主动出站，不需要公网监听。容器监控兼容模式与管理/安全检测互斥，普通账户和空能力集保持。
- 公开地图为本地静态几何数据和国家码，公开接口已有显式字段投影。登录卡片、导航及地图布局保持。
- 指标/系统事件默认 30 天（可配置 1–365），审计 90 天、任务结果 5 分钟/记录 1 天、安全数据独立默认 90 天。不要统一改成 30 天。
